# AI label

Marks content generated by or with AI, to reinforce transparency, accountability, and explainability wherever AI is involved. Two forms: a badge-style `AI label` and an `AI label - Inline` variant for text contexts.

Both variants carry a `Text translation` property (default "AI") for localizing the label text.

## When to use

- Use `AI label` (badge form) at the block/component level — attached to a card, field, or panel that contains AI-generated content.
- Use `AI label - Inline` within running text or dense UI where a full badge doesn't fit.
- Interactive states (Hover/Focus/Active) exist because the label is typically the trigger for the AI explainability popover — see that component.

## Do / Don't

- Do treat this as a required transparency marker, not decoration — apply it anywhere content is AI-generated or AI-assisted, per the file's own guidance.
- Don't reuse the AI label styling for non-AI features just because the visual style seems appealing — it has a specific meaning users learn to rely on.
