# List

Basic ordered or unordered text list, with two indent levels.

## Variant properties — List item

| Property | Options |
|---|---|
| Level | 1, 2 |
| Type | Ordered, Unordered |

Ordered items carry both `Letter text` (e.g. "a.") and `Number text` (e.g. "1.") properties for level 1 vs. level 2 numbering.

## When to use

- Use for simple in-content lists (instructions, bullet points) — not for interactive or data-bearing rows.
- Use `Level 2` for a single level of nested sub-items; for deeper hierarchies use Tree view instead.

## Do / Don't

- Do keep ordered-list numbering consistent with the `Level` property rather than typing numbers manually.
- Don't use List for clickable or selectable rows — use Contained list or Structured list for that.
