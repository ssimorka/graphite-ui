# Security Policy

If you believe you have found a security vulnerability in Graphite UI, please let us know right away.

Please use GitHub's private vulnerability reporting rather than a public issue. Open the Security tab of this repository and click [Report a vulnerability](https://github.com/ssimorka/graphite-ui/security/advisories/new).

We will investigate every legitimate report and do our best to fix the problem quickly.

## Scope

Graphite ships as source that adopters copy into their own projects through the registry at `https://www.graphite-ui.com/r`. Reports about the registry's output, the components, the theme provider and the documentation site are all in scope.
